Add the theme to a site with the gem, a remote theme, or the template.

Updated 2 days ago3 min readApplies to v0.3.0

Pick a mode#

The theme works as a gem, through remote_theme, and after "Use this template".

Note

Classic GitHub Pages builds with a fixed gem set. If you need a plugin that is not on that list, build with GitHub Actions instead.

Add the theme#

Pick the way you want to get the theme, then add it to the site configuration. Your choice is remembered on every page.

_config.yml 
1# _config.yml
2theme: slipway-theme
1# _config.yml
2remote_themeremote_theme: stringLoad the theme from a GitHub repository at build time. Needs the jekyll-remote-theme plugin.
Open remote_theme →: arminazimi/slipway
3plugins:
4  - jekyll-remote-theme
1# On GitHub: Use this template → Create a new repository
2# The theme files are already at the site root.
3title: My docs
Tested Passed on the latest build
Tip

Not sure which to pick? Start with the gem. You can switch later by changing one line.

Build#

Run the build from the site folder.

bash 
1bundle exec jekyll build

Open _site/index.html to see the result.

Warning

Do not commit the _site folder. It is generated on every build and will cause merge conflicts.
